# Interactive Photo Slideshow

A COMP125 front-end project that displays a photo gallery with slideshow controls, a full-size image view, and a favorites list.

## Features

- Browse the gallery with previous and next buttons.
- Start or pause automatic slideshow playback.
- Open a photo in a full-size lightbox.
- Add up to five photos to Favorites and remove them later.
- Responsive layout with custom CSS styling.

## Built With

- HTML5
- CSS3
- JavaScript (DOM manipulation and event listeners)

## Project Files

Keep these files together in the same folder:

```text
assignment3j.html
assignment3j.css
assignment3j.js
logo.jpg
photo01.jpg
photo02.jpg
photo03.jpg
photo04.jpg
photo05.jpg
photo06.jpg
photo07.jpg
photo08.jpg
```

The JavaScript currently loads photos 01–08. Photos 09–12 are not used by this version.

## Run the Project

1. Download or clone the project folder.
2. Make sure the HTML, CSS, JavaScript, logo, and eight gallery photos are all in the same folder.
3. Open `assignment3j.html` in a web browser.

No server or package installation is required.

## Notes

Favorites are kept in the browser page while it is open. They are not saved after the page is refreshed or closed. This is a front-end project and does not use a database or server.
